# Sundered Crowns

Original grand strategy game set in historical Europe, 1 January 1356 – 31 December 1815 (second start: 1492).
WebGPU map, deterministic TypeScript simulation in a Web Worker, persistent online world (planned).

Status: in active development. See `docs/ARCHITECTURE.md`.

## Run locally
```
npm install
npm run dev        # browser game (Vite, http://localhost:5173)
npx tsx tools/sim/run.ts 10   # AI-only simulation for 10 years (headless)
```
Map data is generated by `tools/geo/*.py` (Natural Earth + elevation tiles) and committed under `public/`.

## Online world (optional)
Single player needs no backend. Accounts, cloud saves and the persistent world use your own Supabase project and a
world server (`server/`); without configuration the online panel says so and the game stays fully playable.
```
npm run world        # world server (ws://localhost:8787), DEV login by display name when Supabase is not set
npm run world:fast   # 0.05 s per in-game day, for testing
npx vitest run       # RLS tests on all migrations (PGlite), replay determinism, auth
npm run smoke:online # two scripted clients against a running world server
```
Season length: 1 Jan 1356 – 31 Dec 1815 is 168,013 in-game days (`dateToDay(1816, 0, 1, 1356)`); at 36 s per day that is
168,013 × 36 s = 6,048,468 s = 70.0 days = 10 weeks of real time. Setup and hosting: `docs/DEPLOY.md`.
