# Sundered Crowns – Spieler-Wiki

Willkommen im Wiki von Sundered Crowns. Hier steht, wie die Welt des Spiels funktioniert: was die Simulation berechnet, nach welchen Formeln und auf welche Fachliteratur sie sich stützt.

Das Spiel wird gerade von Grund auf neu gebaut. Das Wiki wächst deshalb Feature für Feature mit. Es beschreibt nur, was beschlossen ist, und markiert Entwürfe als solche.

## Inhalt

- [Die Welt](welt.md): Karte, Massstab, die dauerhafte Welt und die KI-Reiche
- [Wirtschaft](wirtschaft/README.md): Übersicht über alle Wirtschafts-Features
  - [Getreideernte pro Ort](wirtschaft/getreideernte.md) *(Entwurf)*

## Status der Seiten

Jede Seite trägt oben ihren Status:

| Status | Bedeutung |
|---|---|
| **Beschlossen** | Das Design ist abgesegnet. So rechnet das Spiel oder wird es rechnen. |
| **Im Spiel** | Beschlossen und bereits gebaut. |
| **Entwurf** | Ein Vorschlag, der noch nicht abgesegnet ist. Er kann sich ganz oder teilweise ändern. |

## Grundsätze

- **Belegt statt erfunden.** Jede Formel und jede Zahl der Wirtschaft stammt aus wirtschaftshistorischer oder ökonomischer Fachliteratur. Die Fundstelle steht direkt dabei.
- **Ein Feature pro Seite.** Jedes Feature hat seine eigene Seite mit Modell, Daten, historischer Prüfung, Grenzen und Quellen.
- **Schwächen offen.** Wo ein Modell schwächer belegt ist, als es aussieht, steht das unter *Grenzen*.

## Für Mitwirkende

Neue Features werden mit der [Vorlage](_vorlage.md) angelegt und erst nach der Freigabe von **Entwurf** auf **Beschlossen** gesetzt. Sobald ein Feature gebaut ist, wechselt der Status auf **Im Spiel**, und die Seite nennt, wo man es im Spiel sieht.
