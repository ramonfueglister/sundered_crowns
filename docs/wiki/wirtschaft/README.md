# Wirtschaft

**Status:** im Aufbau

Die Wirtschaft von Sundered Crowns wird Feature für Feature neu gebaut. Jedes Feature stützt sich auf ein ökonomisches Modell aus der Fachliteratur und wird an historischen Daten geprüft, bevor es ins Spiel kommt.

## Features

| Feature | Status | Kurz |
|---|---|---|
| [Getreideernte pro Ort](getreideernte.md) | Beschlossen | Jährliche Ernte je Ort aus Fläche, Bodenertrag und Arbeitskräften (Malthus-Produktionsfunktion). Gebaut, wartet auf Abnahme |

Weitere Themen wie Verbrauch und Hunger, Bevölkerungswachstum, Preise, Handel und Steuern bekommen je eine eigene Seite, sobald ihr Design vorliegt.

## Wie ein Feature entsteht

1. Ein einzelnes Feature wird mit Modell, Daten und Quellen vorgeschlagen. Es erscheint hier als **Entwurf**.
2. Nach der Freigabe wird es **Beschlossen**.
3. Sobald es gebaut ist, steht es auf **Im Spiel**, und die Seite sagt, wo man es im Spiel sieht.
